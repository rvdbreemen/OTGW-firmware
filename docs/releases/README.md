# Release notes index

Canonical locations for release documentation:

- **Current release notes** (the release on `main`): repository root, as `RELEASE_NOTES_<version>.md`
- **Previous release notes**: `docs/releases/`
- **Archived historical release notes** (pre-1.3.5): `docs/releases/archive/`

Each release also has a GitHub release body, kept alongside its notes as `RELEASE_GITHUB_<version>.md`.

At release time the outgoing version's notes and GitHub body move from the repository root into this directory, and the new version's notes take their place at the root.

## Current release: v1.7.4

- [RELEASE_NOTES_1.7.4.md](../../RELEASE_NOTES_1.7.4.md) ([GitHub body](../../RELEASE_GITHUB_1.7.4.md)) ([download](https://github.com/rvdbreemen/OTGW-firmware/releases/tag/v1.7.4))
