    PIC diagnose interactive test menu on the PIC serial line
    

    
    

    
    
      The PIC is running diagnostic firmware, so it offers a test menu instead of
      speaking OpenTherm. Type a test number and press Enter. The menu reads a
      whole line, so send one number at a time.
    
    

    
    
      DIAG ›
      
      
    
    
    

    
    

    
    
      What happens next differs per test. Tests 1, 2 and 3 keep running until you press
      Enter with the box empty, and test 1 produces no output at all while it runs, so a
      quiet screen is normal there. Test 5 ends by asking you for a reference voltage
      setting. Test 4 needs a loop between the two interfaces, and is the one test that
      interrupts communication between thermostat and boiler. Which connections each test
      needs, and how to read its results, is described on
      Schelte Bron's diagnostic firmware page.
