## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Decided 2026-10-15 (maintainer): v2-only, so the 768K LittleFS of the safeboot layout fits. Remove index.html, index.js, graph.js, sat.js, sat-slider.js, theme-toggle.js, echarts-theme.js and design.html from data/. Remove settings.ui.bUseV2: the root (/, /index, /index.html) always serves v2.html. An old ui_usev2 key in settings.ini is ignored on read, so no migration step is needed. Remove the UI toggle buttons. Keep the FSexplorer fallback when v2.html is missing. Needs an ADR, which supersedes the coexistence decision of ADR-152. Starts only after the gap audit (TASK-1223.11) and its port tasks are done or consciously dropped.
