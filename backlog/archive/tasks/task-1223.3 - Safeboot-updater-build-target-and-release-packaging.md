## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
2026-10-15: build.py now has:
- read_partition_table() for the CSV;
- build_safeboot(), which runs pio -d safeboot, fails when the image exceeds the safeboot partition and copies it to build/OTGW-safeboot-<semver>.bin;
- create_merged_binary(), which adds safeboot at its partition offset when the table has one, and errors when the image is missing.
All of this is a no-op on the current table. Host tests in tests/test_build_safeboot.py: partition invariants, the ADR-191 layout check, the oversize safeboot gate and the no-op on the old table (8 OK). AC1/AC2 need the layout switch.

Build log .tmp/build-layout2.log: 'Safeboot updater: 931648 B of 983040 B (51392 B free)'. Merged-full contains bootloader @0x0 (0xE9), the partition table @0x8000 (0xAA50, safeboot label), boot_app0 @0xE000, safeboot @0x10000, app @0x100000 and LittleFS @0x330000 (merge command in the log). bug-900 fixed on the way: the merge had no bootloader; that is now a hard error.
<!-- SECTION:NOTES:END -->
