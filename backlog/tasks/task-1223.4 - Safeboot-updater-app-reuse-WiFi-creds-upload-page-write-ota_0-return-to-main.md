## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Updater behaviour: join WiFi with the creds main firmware stored in NVS (WiFi.persistent(true), nvs.net80211), same hostname, serve one HTTP upload page (no HTTPS), write ota_0 with verify, set ota_0 as boot partition, restart. Fallback AP when no creds. Decide whether W5500 Ethernet (OTGW32) is needed in safeboot.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 On a bench unit, safeboot joins the existing WiFi without reprovisioning and serves the upload page at the device IP (curl transcript)
- [ ] #2 Uploading a valid image writes ota_0 and the unit restarts into it; uploading a truncated/invalid image is rejected and safeboot stays up (bench transcript)
- [ ] #3 Safeboot upload authentication is decided in the ADR (TASK-1223.1) and implemented accordingly. Safeboot is reachable unauthenticated by anyone on the LAN, and the device enters it by itself after a failed image, so ADR-056 protection of the main firmware does not cover it
- [ ] #4 On Classic (PIC) boards safeboot writes nothing to the PIC UART0 link beyond unavoidable ROM/bootloader output; the IDF log level is lowered so esp_image/boot errors do not reach the PIC (serial capture on a Classic board)
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
2026-10-14 from TASK-1222: the factory slot has ~36 KB slack (946,327 B in 983,040). Adding W5500 Ethernet or auth to safeboot probably forces a 1024K factory partition. Without Ethernet in safeboot, an Ethernet-only OTGW32 cannot reach safeboot and stays USB-only.

Decided 2026-10-15:
- Auth: Basic Auth when the admin password is set. Main firmware mirrors that password into NVS, and safeboot reads it there. With no password set the route is open, which is the same as main (ADR-056 parity). An empty password must never lock the user out.
- No W5500 Ethernet in safeboot: WiFi with the NVS creds, plus a fallback AP.
- The size must stay within 960K; the build gate is in TASK-1223.3.
<!-- SECTION:NOTES:END -->
