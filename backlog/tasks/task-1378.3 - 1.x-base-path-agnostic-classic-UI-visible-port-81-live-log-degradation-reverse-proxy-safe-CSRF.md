## Description

Epic item C (1.x), scoped by TASK-1378.2. 2.0.0 sibling: TASK-1377.5 (dev backlog); the CSRF decision is taken in its ADR (amending ADR-056) and mirrored here.

Research (docs/research/2026-10-25-home-assistant-ui-integration.md sections 4 and 5): build only what rewrite rules cannot fix cleanly. (1) index.js/index.html: page-relative URLs (or X-Ingress-Path as base) for /api/, /pic, /update, /ResetWireless, /FSexplorer and assets. (2) Port-81 live log: when served over https or through a proxy (path prefix not '/'), show a clear 'live log only on direct access' state instead of failing silently; moving the WebSocket to port 80 only if TASK-1378.2 shows it is cheap. (3) CSRF: isSameOriginRequest() restAPI.ino:107 must accept a proxied same-origin request and still reject a foreign-origin POST; write a 1.x ADR amending ADR-054 first. ESP8266 RAM and PROGMEM rules apply.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- Scope from TASK-1378.2: page-relative URLs (index.js basePath/localURL/APIGW, FSexplorer.html, updateServerHtml.h, FSexplorer.ino Helper + doRedirect), proxy notice for the live log (isProxied = https || basePath != /), complete 303 header for upload/delete (FSexplorer.ino Header[]). WebSocket stays on port 81 (moving it is not cheap on ESP8266WebServer + WebSocketsServer).
- PIC settings cache key gets the base path only when proxied, so direct access keeps its existing key.
- CSRF: no code change. hass_ingress passes the browser Host, so Origin/Host match; with headers: host: <ip> or nginx default Host the check refuses (403), as intended. Guide tells users to keep Host.
- AC#4 (1.x ADR amending ADR-054) open: no change to the ADR-054 decision was made, so there is nothing to amend. Dropping AC#4 needs the maintainer's OK (and the 2.0.0 ADR for TASK-1377.5 may still decide differently for 2.0.0).

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Classic UI works behind HA ingress and any sub-path reverse proxy; live log degrades visibly.

- Before (bench, beta.6+12975b4): behind HA ingress HTTP/HTTPS and nginx, 6-7 requests per page hit the proxy root (404), header [version], upload 502, FSexplorer forms outside the path, live log silent.
- After (beta.6+54cbe02): validate_ingress.py 5/5 required scenarios PASS (direct with live log Connected; HA ingress HTTP and HTTPS; nginx HTTPS and HTTP), 0 escaped requests, settings write 200, upload 303, notice shown. Same with an admin password set. Firmware OTA through the ingress panel OK (43.8 s).
- Upload 303 header fix: nginx 3/3 502 on released beta.5, 3/3 303 after.
- CSRF unchanged, curl before (beta.5) and after identical: foreign Origin 403, same Origin 200, no auth 401, foreign-Origin upload 403 and not written.
- Build OK (773436 B flash, 53388 B globals), evaluate.py --quick 0 failed, host tests 0 failures.
- Open: AC#4 (ADR) pending maintainer decision, see notes.
