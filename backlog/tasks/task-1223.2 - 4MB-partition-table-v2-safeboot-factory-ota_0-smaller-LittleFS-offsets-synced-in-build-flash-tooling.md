## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
New partitions CSV for the 4MB targets per the ADR (TASK-1223.1). Decided 2026-10-15:
- safeboot app/factory at 0x10000, size 0xF0000 (960K);
- app0 ota_0 at 0x100000, size 0x230000 (2240K);
- LittleFS at 0x330000, size 0xC0000 (768K);
- coredump at 0x3F0000, size 0x10000.
Update every hardcoded offset: build.py (firmware_offset/fs_offset), flash_otgw.bat (APP_OFFSET/FS_OFFSET plus the echo text), flash_esp.py, and the merged-image assembly. LittleFS must hold the v2-only minified image (measured 668 KiB, about 100 KiB runtime room).
