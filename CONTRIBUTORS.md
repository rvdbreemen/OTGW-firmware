# Contributors

OTGW-firmware exists because of many people: the maker, the people whose work it builds on, and a community that has tested, reported and helped others since 2021. Thank you.

This file is the full list. The About screen in the web UI shows a short version. It is updated with every public stable release; the counts below are from 2026-11-20.

Names are shown as people use them in public: a GitHub handle, or a Discord display name. Most active first.

## Maker

- **Robert van den Breemen** (rvdbreemen): author and maintainer since 2020.

The firmware is written with the help of AI coding assistants, under the maintainer's direction and review. Over time these were GitHub Copilot, Claude Code and OpenAI Codex.

## Credits

The firmware builds on the work of:

- **Schelte Bron**: designed the [OpenTherm Gateway](https://otgw.tclcode.com/) and its PIC firmware, wrote the OTGWSerial library, and gave access to the PIC upgrade routines. If you want to thank him, donate on his site.
- **George Ntellas** (Sergeant D): designed the SAT algorithm.
- **Alex** (Alexwijn): developed the original [SAT component for Home Assistant](https://github.com/Alexwijn/SAT), which the SAT controller in 2.0 is ported from.
- **Nodo Shop**: sells the [OpenTherm Gateway kit](https://www.nodo-shop.nl/).
- **RobR**: the S0 pulse counter.
- The libraries in the firmware and their authors: OpenTherm (Ihor Melnyk), espMqttClient (Bert Melis), FSexplorer (Jens Fleischer), AsyncTCP and ESPAsyncWebServer (ESP32Async), NimBLE-Arduino (h2zero), WiFiManager (tzapu), SSD1306Ascii (greiman), OneWire, DallasTemperature, AceCommon, AceSorting and EthernetESP32.
