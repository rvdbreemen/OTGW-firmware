### Build / tooling

Concurrent runs share `.pio/build` → 0xC0000142 or `OTGW-firmware.ino.cpp: No such file or directory`. Recovery: `rm -rf .pio/build/<env>`, rebuild solo. Only `buildfs` parallelizes. - Firmware epoch is AceTime `time(nullptr)`, never TimeLib `now()`.
- Combo flash budget (ADR-127): esp32-combo at 98.4% of the 1.875MB app slot; `-flto` already on.
- Dict-spread in `TARGETS` silently inherits later keys (`slug`) → artifact name collisions. Set explicit values. (bug-120)

- **SAT PID vs pid.py (TASK-1195, 2026-10-03)**: the firmware derivative is timed by when the room temperature changed (`_pid_roomTempChangedMs`), and its reference temperature moves only with the timer (`_pid_derivRefTemp`, B'). SAT Python feeds pid.py the RAW HA entity (climate.py:271-279, no smoothing). The firmware's TASK-894 comment claiming "already-smoothed" input is not in the SAT code. pid.py itself under-reads sensors that change every tick (R1: 40% of the true slope). The PID error is rounded to 3 decimals by `satPidError()`, as in TemperatureState.error. Proof harness: `test/host/test_sat_pid_derivative.py` (real SATpid.ino + zone step + room EMA + pid.py oracle, mutants).
- **Zone PID Kp divisor is inverted (found 2026-10-03)**: `satZonePidStep()` uses `iHeatingSystem == 1 ? 4 : 3` (radiators get the floor divisor). The primary PID uses `UNDERFLOOR ? 4 : 3` (TASK-891.8 fixed only the primary).
- **Marker-synchronized race test (TASK-1176, 2026-10-03)**: AsyncSimpleTelnet sends from the calling task straight into lwIP, so a `DebugTln` marker printed inside a loopTask window reaches the host while the window is still open. For a `delay(2000)` stretch the host saw open-to-close as 2.0 s. A host that fires a REST call on the marker then lands inside the window. Check that gap on the host first; if it is near 0, phase-lock to the next frame instead.
- **Two clocks on the rig (2026-10-03)**: `mosquitto_sub -F %U` stamps come from the Docker/WSL2 VM clock. They were offset from Windows host epoch by -0.5 to +0.6 s and drifted between runs. For ordering, use a single-clock telnet table (gate reasons such as `publish[force]` / `[interval]` / `skip[no-change]`, plus markers), never cross-clock broker times.
- **getMaxAllocHeap() counts RTC memory (TASK-1162, 2026-10-04)**: `ESP.getMaxAllocHeap()` = `heap_caps_get_largest_free_block(MALLOC_CAP_INTERNAL)`, which includes RTC fast memory. It backs `platformMaxFreeBlock()` and both REST/file gates. In the storm run that number was the RTC block (4-7.6 KB) while 2312 B INTERNAL|DEFAULT (0x1800) mallocs failed and the DRAM largest block was 1524 B. For "can a malloc succeed", measure `MALLOC_CAP_INTERNAL|MALLOC_CAP_DEFAULT`.
- **AsyncWebServer ack timeout closes, does not abort**: after 5 s without ACK (CONFIG_ASYNC_TCP_MAX_ACK_TIME) `AsyncWebServerRequest::_onTimeout` calls `_client->close()` = graceful `tcp_close`, which keeps queued TX data. Only `AsyncClient::abort()` (`tcp_abort`) frees it. Override per request with the public `req->client()->onTimeout(...)`, no library change.
- **/.health static URL as a flash-write detector**: the FS listing hides dotfiles, the static server serves them. Delete `/.health`, run N calls, GET `/.health` (404 = not written). `usedBytes` in the listing is useless as evidence (5% margin, clamped to 100%).
- **HA discovery harness**: `test/host/test_ha_discovery_json.py --old-rev 8795bacc0` compiles the real MQTTHaDiscovery.cpp; parts A-E cover composers, dispatcher permutations, removals, the TASK-1201 clear and injected publish failures. Identify duplicates by uniq_id, never by name: legacy `thermostat_connected` is a genuine entity.
- **NimBLE TU include order (TASK-1199, 2026-10-03)**: IDF component includes arrive via `-iprefix`/`-iwithprefix`, which are searched after every `-I`. A NimBLE-Arduino TU gets only four `-I` dirs: the lib's src, the sdkconfig dir (`esp32s3/qio_qspi/include`), cores, variants. Every sdkconfig.h includer seen uses quotes, and the framework sdkconfig.h is `#pragma once`.
